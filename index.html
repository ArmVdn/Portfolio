Over mij

Ik ben een gemotiveerde frontend developer in opleiding met een sterke interesse in webontwikkeling en digitale toegankelijkheid. Ik werk graag aan projecten waarin techniek, gebruiksvriendelijkheid en design samenkomen.

Tijdens mijn leertraject richt ik mij op HTML, CSS, JavaScript, React, Debugging, Vs Code en web accessibility. Ik vind het belangrijk om niet alleen te begrijpen hoe iets werkt, maar ook waarom een bepaalde oplossing de beste keuze is.

  • Toegankelijkheid volgens WCAG-richtlijnen 2.2

  • Responsive webdesign
